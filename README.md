# 4WOMAN'S — App frontend do Google AI Studio

App de desenvolvimento e beleza feminina com o guia completo da Dieta Amalfitana, hábitos diários e rotinas de longevidade. Aplicação 100% frontend (React + Vite + Tailwind), sem necessidade de chave de API.

Ver no AI Studio: https://ai.studio/apps/a9e0c020-1737-4990-a714-a9529beb86af

## Rodar localmente

**Pré-requisitos:** Node.js 18+

1. Instalar dependências:
   `npm install`
2. Rodar o app:
   `npm run dev`

## Build

`npm run build` gera a pasta `dist/` com os arquivos estáticos prontos para hospedagem.
